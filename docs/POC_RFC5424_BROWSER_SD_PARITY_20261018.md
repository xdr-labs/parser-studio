## Frozen independent oracle before candidate scoring

The ten independently authored **standards-derived synthetic** examples were
generated by scripts/poc/freezeStdRfc5424BrowserParity.py and frozen in
scripts/poc/standardsRfc5424BrowserParity.pinned.json, SHA-256
8e5866687e04ee6f796278a6e7cce0a79e4a42222d7e79f02f67035f9fcdfd26.

Six positive cases cover unknown backslash escaping, repeated PARAM-NAME
occurrences, mixed UTF-8/backslash/repetition, defined escape sequences,
valid '[' and backslash in SD-NAME, and adjacent SD-ELEMENTs.
Four negative controls cover repeated SD-ID, raw unescaped ']', unterminated
PARAM-VALUE, and unquoted PARAM-VALUE.

Ordered field occurrence, exact raw source lexeme, decoded value, and
absolute UTF-8 byte start/end are computed from the independently authored
literal source before the candidate parser is scored. These are not verified
publisher device-wire captures or Fluentd/Stellar native goldens.

  instead of creating a second lexer: accept the normative SD-NAME set,
  allow repeated parameter names, preserve unknown escape sequences literally.

  There is no false claim that the browser maps native individual

  subset. Transport/TLS/native and relay origin parity are not qualified.
